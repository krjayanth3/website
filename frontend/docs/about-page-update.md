# About editorial redesign

1. **Files modified:** `app/about-page.tsx`, `app/about-page.module.css`, `app/site-routes.ts`, `app/technology-constellation-data.ts`, and this report. The shared background file only gains an About-specific preset and `/company` mapping; other presets are unchanged. Hash comparison confirms Home, Services, Products/R&D, Tech at ABCX, Blogs, navbar, footer, and process components were not edited.
2. **Duplication removed:** Removed About's six-capability grid, eight engineering cards, previous R&D preview, glass hero plates, and repeated boxed closing CTA. No wheels, technology logo grids, or homepage sections remain in About.
3. **New sections:** Brand identity hero; Our Story; four numbered principles; Our Focus constellation; Today/Tomorrow direction; concise Beyond Software; one unboxed final CTA. Supplied company copy is used without fabricated business claims. Tomorrow remains exploratory.
4. **Identity animation:** CSS fades and contracts the remainder of Alpha/Beast/Code, retaining the gold A/B/C/X initials. The official logo resolves beneath. IntersectionObserver starts the 2.2-second sequence once; the final state remains stable after scrolling away and returning. Its container reserves space. Static content establishes the company name and abbreviation independently of animation.
5. **Effects:** One-time 700ms section reveals; two-pixel constellation node drift; faint staggered line illumination; subtle principle, node, and link hover highlights. Animations pause offscreen/when the document is hidden. No rotating wheels, cards, particle system, or new dependencies. About uses 10/6/4 background logos for desktop/tablet/mobile instead of the previous 18/10/6, with lower opacity.
6. **Responsive:** Split editorial layouts stack naturally. Principles switch from three-column rows to number plus text. Today/Tomorrow becomes vertical below 640px. Mobile constellation becomes a central logo above two columns of labels, without lines or drift. Tested 1920, 1440, 1280, 1024, 768, 640, 390, and 360px; no horizontal overflow. Desktop and mobile screenshots inspected; Home and About visually compared.
7. **Accessibility:** One H1, labelled sections, semantic ordered principles and focus-area list, decorative brand animation hidden from assistive technology, real links, visible keyboard focus. Reduced motion disables identity, drift, pulses, and reveals while keeping all content visible. Keyboard tab order and focus styling verified. Both themes retained.
8. **SEO:** Existing metadata system retains the About title and updates the description to company engineering, innovation, research, intelligent systems, and practical solutions. About navigation remains active; existing footer and CTA routes are reused.
9. **Validation:** `npm run lint`, `npx tsc --noEmit`, and `npm run build` passed. No formatter or automated test runner is configured. Temporary browser assertions verified responsive layout, section and item counts, no duplicated process/wheels, one-time animation behavior, reduced motion, keyboard navigation, links, metadata, and console output. No console or hydration errors observed.
